# Shirox modules

Personal, unofficial Anidap adapters for Shirox. This repository contains module code and manifests only; it does not host anime or media files and is not affiliated with Anidap or Shirox.

Add either manifest in Shirox Settings → Modules:

- SUB: https://mofongoler-pixel.github.io/shirox-modules/anidap-sub.json
- DUB: https://mofongoler-pixel.github.io/shirox-modules/anidap-dub.json

The phone calls the provider directly. Hosting only serves module installation/update files. New episodes are retrieved from the provider without updating the module. Module-code updates depend on Shirox's update controls; this repository does not provide a background updater.

Version0.1.1: permanent HTTPS script URLs. Search, episode and stream-response checks passed on macOS. Actual playback on iOS remains unverified. Provider changes may require module updates. No paid-service access bypass, credentials or authentication tokens are included.
