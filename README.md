# Shirox modules

Personal, unofficial Re:ANIME and Anidap adapters for Shirox. This repository contains module code and manifests only; it does not host anime or media files and is not affiliated with the providers or Shirox.

## Install

In **Shirox → Settings → Modules**, add the manifest URL for your preferred source:

| Source | Manifest |
| --- | --- |
| Re:ANIME SUB | https://mofongoler-pixel.github.io/shirox-modules/reanime-sub.json |
| Re:ANIME DUB | https://mofongoler-pixel.github.io/shirox-modules/reanime-dub.json |
| Anidap SUB | https://mofongoler-pixel.github.io/shirox-modules/anidap-sub.json |
| Anidap DUB | https://mofongoler-pixel.github.io/shirox-modules/anidap-dub.json |

## Re:ANIME status

**Version 0.1.2:** video playback confirmed on an iPhone running Shirox 1.0.6 on November 8, 2026. Search, episode lists and stream resolution also passed live checks for SUB and DUB. Subtitle rendering and English DUB audio selection have not yet been confirmed on the phone.

Streaming works directly on the phone. No Mac, local server or shared Wi-Fi connection is required. GitHub Pages hosts the module files only.

If a DUB stream starts with Japanese audio, select English in the player's audio-track menu. SUB prefers full-dialogue English subtitle tracks when available.

See [Re:ANIME details](REANIME.md) for compatibility and implementation notes. Provider changes may affect playback.
